# ContentCraft AI

A frontend-only writing workspace built with React, Vite and plain CSS.
All "AI" output is **simulated sample content** assembled in the browser from your inputs. There is no backend, database or API.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

Production build: `npm run build`, then `npm run preview`.

Data (history, favorites, settings) is stored in your browser's localStorage.
To reset everything, clear site data for localhost in your browser.
